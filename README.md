Escalated to Tier 2: a hopeless tech support agent's one-line escalation joke for make.fun's "Have You Tried Turning It Off?" bounty — one funny line, under 200 characters, that a hopeless tech support agent says to a desperate customer.

> Your ticket has been escalated to Tier 2, which is me, in a different chair, with the same manual.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt`. Deterministic: no network, no randomness, no clock, no environment input. See [STUDY.md](STUDY.md) for why this line was chosen.
